Enviar archivos por correo

Selecciona los archivos y envíalos directamente a un correo. El formulario abrirá tu cliente de correo con el mensaje preparado.

Nota: este formulario intenta abrir tu cliente de correo con los datos completos. Las imágenes y documentos seleccionados pueden o no adjuntarse automáticamente según tu navegador y cliente de correo. Para enviar archivos automáticamente sin usar un cliente local, se necesita un servicio de backend o una integración con un proveedor de correo.
